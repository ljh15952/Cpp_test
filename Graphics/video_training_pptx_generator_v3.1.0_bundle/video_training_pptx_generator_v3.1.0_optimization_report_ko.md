# 범용 설명 영상 PPTX 자동 생성 v3.1.0 최적화 보고서

## 1. 장애 분석

실행 로그에서 전사와 초기 슬라이드 계획은 정상적으로 완료됐습니다. 실패 지점은 `4/6 スライド全体を編集しています` 단계였습니다.

최종 오류는 다음과 같습니다.

```text
スライド全体編集のJSON応答を3回解析できませんでした:
内部LLMのJSON応答がオブジェクトではありません。
```

원인은 다음 네 가지입니다.

1. **전체 자료를 하나의 대형 JSON으로 다시 출력하도록 요구**
   - 초기 계획과 최대 36,000자의 전사 근거를 한 번에 입력했습니다.
   - 로컬 LLM이 긴 출력에서 객체 대신 배열을 반환하거나 JSON 구조를 불완전하게 만들 가능성이 높았습니다.

2. **정상적인 JSON 배열을 오류로 처리**
   - 편집 결과가 `[{...}, {...}]` 형태의 유효한 JSON 배열이어도 최상위 객체가 아니라는 이유로 실패했습니다.

3. **보조 편집 단계 실패가 전체 생성 실패로 전파**
   - 초기 슬라이드 계획은 이미 존재했지만 전체 편집 JSON 오류가 발생하면 프레임 추출과 PPTX 생성을 진행하지 않았습니다.

4. **시스템 프롬프트의 1회 실행 규칙이 실제 모델 동작을 완전히 통제하지 못함**
   - 첫 번째 오류 후 모델이 “もう一度試します”라고 응답하고 동일 Tool을 자동 재호출했습니다.
   - 결과적으로 전사와 계획 생성 비용이 중복 발생했습니다.

## 2. v3.1.0 수정 사항

### 2.1 전체 일괄 편집 제거

기존:

```text
전체 슬라이드 + 전체 근거 → LLM 1회 → 대형 완성 JSON
```

변경:

```text
로컬 1차 편집
→ 최대 4장 단위 LLM 편집
→ 안전한 필드 병합
→ 로컬 최종 편집
```

기본 설정:

| 설정 | 값 |
|---|---:|
| `editor_batch_slides` | 4 |
| `editor_concurrency` | 2 |
| `editor_timeout_seconds` | 240초 |
| `editor_max_tokens` | 6,000 |
| `editor_evidence_characters` | 10,000자/배치 |

### 2.2 JSON 배열 호환

내부 LLM이 최상위 JSON 배열을 반환하면 호출 목적에 따라 자동으로 변환합니다.

```text
장 분석 호출:  [...] → {"chapters": [...]}
슬라이드 호출: [...] → {"slides": [...]}
```

또한 `result`, `data`, 이름이 다른 단일 배열 키도 가능한 범위에서 정규화합니다.

### 2.3 편집 실패 시 생성 계속

분할 편집에서 다음 오류가 발생해도 해당 배치만 초기안으로 되돌리고 전체 작업을 계속합니다.

- JSON 파싱 오류
- 최상위 구조 오류
- 시간 초과
- 연결 오류

로컬 편집 단계에서 다음을 처리합니다.

- 저정보 슬라이드 제거
- 일반 제목 교체
- 플레이스홀더 제거
- 중복·인접 단편 슬라이드 통합
- 불완전한 조작 단계 제거
- 슬라이드별 강사 노트 보완
- 시간순서와 근거 인덱스 유지

### 2.4 계획 단계 포맷 오류 폴백

장 구성 또는 초기 슬라이드 계획이 JSON 형식 오류나 시간 초과로 실패하면 규칙 기반 계획을 생성한 뒤 편집 단계로 진행합니다.

인증 실패, 사용자 정보 누락, Open WebUI 내부 API 부재 등 환경 구성 오류는 계속 명시적 오류로 처리합니다.

### 2.5 Tool 내부 중복 실행 방지

동일한 `chat_id`와 `message_id`로 Tool이 다시 호출되면 최초 실행 결과를 재사용합니다.

```json
{
  "duplicate_request_reused": true,
  "automatic_retry_performed": false
}
```

따라서 모델이 시스템 프롬프트를 무시하고 같은 메시지에서 재호출해도 전사와 PPTX 생성은 한 번만 수행됩니다.

### 2.6 시스템 프롬프트 강화

- `status=error` 반환 시 즉시 턴 종료
- “もう一度試します” 후 자동 실행 금지
- 동일 사용자 메시지에서 `generate_training_material` 재호출 금지
- 분할 편집 실패 시 Tool 내부 폴백을 신뢰
- `duplicate_request_reused=true`를 신규 생성 성공으로 설명하지 않음

## 3. 유지한 요구사항

- 다양한 설명·조작·강의 영상 대응
- 공개 Tool은 `debug_ping`, `generate_training_material`만 제공
- 품질점수, 평가표, 공개 차단, 수정 Tool 없음
- 성공 후 작업 디렉터리에는 PPTX만 보존
- 최소 슬라이드 수를 맞추기 위한 저정보 슬라이드 강제 생성 없음

## 5. 확인이 필요한 범위

현재 환경에서는 실제 Open WebUI 내부 LLM과 원본 36.9MB 영상을 연결한 전체 통합 실행을 수행하지 않았습니다. 따라서 배포 후 동일 영상으로 한 번 재시험해야 합니다.

정상 동작 시 기존처럼 전체 편집 단계에서 8분 동안 3회 실패하지 않고, 일부 편집 배치가 실패하더라도 프레임 추출과 PPTX 생성 단계로 계속 진행해야 합니다.
