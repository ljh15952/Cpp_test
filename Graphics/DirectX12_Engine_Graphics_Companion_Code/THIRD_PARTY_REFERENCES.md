# Third-party references

이 부록 코드는 외부 소스 코드를 복사한 패키지가 아니다. 설계와 API 사용 시 다음 1차 자료를 참고하도록 교재에서 인용한다.

- Microsoft Direct3D 12 programming guide and DirectX Graphics Samples
- Microsoft HLSL/DXC, PIX, DRED, Enhanced Barriers, DXR, Mesh Shader,
  Variable Rate Shading, Sampler Feedback, Work Graphs, DirectStorage docs
- Kajiya, *The Rendering Equation* (1986)
- Cook and Torrance, *A Reflectance Model for Computer Graphics* (1981)
- Burley, *Physically Based Shading at Disney* (2012)
- Karis, *Real Shading in Unreal Engine 4* (2013)
- Olsson et al., *Clustered Deferred and Forward Shading* (2012)
- Karis, *High Quality Temporal Supersampling* (2014)
- Schied et al., *Spatiotemporal Variance-Guided Filtering* (2017)
- Bitterli et al., *Spatiotemporal Reservoir Resampling* (2020)

정확한 서지 정보와 링크는 EPUB의 참고문헌을 확인한다.
